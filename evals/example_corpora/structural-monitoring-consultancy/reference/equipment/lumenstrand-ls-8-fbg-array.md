# Equipment sheet: Lumenstrand LS-8 fibre Bragg grating array

- Maintained by: Maren Lisk
- Last reviewed: 14 July 2025

## Description

The LS-8 is a single fibre carrying eight Bragg gratings at 4.5 nm spacing from
1530 nm. Seven gratings are for bonding; the eighth is packaged in a loose tube
as a strain-free reference (**SFR**) grating for temperature compensation.

## Key figures

| Property | Value |
| --- | --- |
| Gratings per array | 8 (7 bonded, 1 SFR) |
| Gauge length | 10 mm |
| Strain sensitivity | 1.21 pm/µε |
| SFR temperature sensitivity | 9.7 pm/°C (array certificate) |
| Grating spacing on the fibre | 1.2 to 1.5 m, to order |

## Note on the datasheet figure

The manufacturer's datasheet prints 10.8 pm/°C. That is the bare-grating value
before packaging. Always use the array calibration certificate value, which for
every LS-8 batch we have bought is 9.7 pm/°C.

## Reading

Read with a Prisma FI-4 interrogator.
