# Equipment sheet: Geovane VW-4200 vibrating-wire strain gauge

- Maintained by: Priya Venn
- Last reviewed: 6 January 2025

## Description

The VW-4200 is a vibrating-wire strain gauge with a 150 mm gauge length and an
integral 3 kΩ thermistor. It is supplied for arc welding to steel or for
bonding to concrete and masonry with mounting blocks.

## Key figures

| Property | Value |
| --- | --- |
| Range | 3,000 µε |
| Resolution | 0.4 µε |
| Batch gauge factor | 3.304 (check the batch certificate) |
| Thermistor | 3 kΩ at 25 °C |
| Operating temperature | −20 to +80 °C |

## Reading

Read with a Corlen CR-16 datalogger. Each reading pairs a frequency with a
thermistor temperature; apply the thermistor correction before reporting strain.
