# Installation of vibrating wire strain gauges: Marlow cable tunnel

- Ref: MI/2310/IR01
- Client: Ostrand Energy Networks
- Attention: Mr Idris Fell
- Prepared by: Priya Venn
- Checked: Callum Draycott
- Date: 26 September 2023

## 1. Introduction

Ostrand Energy Networks asked Marrick Instrumentation to install strain gauges
on the segmental lining rings 210 to 228 of Marlow cable tunnel before the
piling for the Marlow Road flyover above the tunnel. This note records the
installation and the initial readings.

## 2. Instrumentation

| Item | Type | Serial / batch |
| --- | --- | --- |
| Strain gauges | 9 No. Geovane VW-4200 vibrating wire, surface mounted | Batch GV-2310-19 |
| Datalogger | Corlen CR-16, 16 channel | CR16-0451 |
| Telemetry | 4G modem to Marrick Atlas | MOD-5001 |

## 3. Installation record

Gauges were installed from 11 to 12 September 2023. Mounting blocks were fixed
with two-part epoxy and each gauge was fitted with a steel protective cover.
Cables were run in flexible conduit to the logger enclosure.
